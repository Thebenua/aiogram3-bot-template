# Безопасность

Не публикуйте токены, `.env` и персональные данные в issues или коммитах. Если токен бота оказался раскрыт, отзовите его через BotFather и настройте новый.

О проблемах безопасности сообщайте автору лично через [Telegram](https://t.me/Thebenua), приложив описание воспроизведения без действующих секретов.
