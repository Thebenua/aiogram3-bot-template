# Benua · Telegram Bot Template

Основа Telegram-бота на Python и aiogram 3 для развития в прикладной продукт: приём заявок, диалоги, интеграции с сервисами и ИИ-помощники.

Проект связан с направлением [Benua — ИИ и разработка цифровых продуктов](https://thebenua.online/): соединять логику, данные и интерфейс вокруг понятного действия пользователя. Здесь интерфейсом служит Telegram.

Это стартовый каркас. Сейчас бот отвечает на `/start`; остальные сценарии добавляются под конкретную задачу.

## Что уже есть

| Компонент | Состояние в репозитории |
| --- | --- |
| Запуск бота | Асинхронный polling через `Dispatcher` |
| Обработка команд | Отдельный роутер с `/start` |
| Конфигурация | `pydantic-settings`, чтение `.env`, токен как `SecretStr` |
| Логи | Стандартный `logging` на уровне INFO |
| PostgreSQL и Redis | Зависимости и сервисы Compose; подключения из Python ещё нет |
| Docker | Заготовка Compose; Dockerfile пока отсутствует |
| ИИ и внешние API | Точки развития; готовых интеграций пока нет |

Нагрузочные тесты, CI и готовность к production этим репозиторием пока не подтверждены.
